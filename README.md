# Project: Todo List | The Odin Project

## Description
This project is a web-based Todo List app from [The Odin Project](https://www.theodinproject.com/about). The purpose of this project is to demonstrate and practice the lessons I learned in [JavaScript Course](https://www.theodinproject.com/paths/full-stack-javascript/courses/javascript#organizing-your-javascript-code) including Objects so either using Classes (ES6 Modules), Constructors, or Factories, and as well as Webpack, and OOP Principles (SOLID).
